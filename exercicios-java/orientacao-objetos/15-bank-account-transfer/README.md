# 15 - BankAccount with Transfer

Exercicio com conta bancaria, saldo inicial e transferencia entre contas.

## O que treina

- Sobrecarga de construtor
- Encapsulamento
- Deposito, saque e transferencia
- `toString`

## Como funciona

O programa cria duas contas, mostra os dados antes e depois da transferencia e valida se a operacao pode acontecer.
