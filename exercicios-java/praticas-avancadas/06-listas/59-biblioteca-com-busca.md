# 59 - Biblioteca com Busca

## Categoria
Listas

## Nível
Intermediário

## Contexto
Treino com ArrayList, buscas, remoções, ordenação e manipulação de coleções dinâmicas.

## Enunciado
Cadastre livros e permita busca por título ou autor.

## Regras
- Use List quando a quantidade de registros não for fixa.
- Trabalhe com busca por id, nome ou posição quando o enunciado pedir.
- Mostre o resumo final de forma organizada.

## Entrada
Título, autor e ano.

## Saída
Mostre o livro encontrado ou a mensagem de ausência.

## Exemplo
### Entrada
```text
Java Basico
Nelio
2024
POO na Pratica
Marcos
2025
```
### Saída
```text
Livro encontrado: Java Basico
```
