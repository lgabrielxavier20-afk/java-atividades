# 79 - Contador de Palavras

## Categoria
Extras

## Nível
Desafio

## Contexto
Treino adicional com validação, datas, arquivos e processamento um pouco mais completo.

## Enunciado
Leia um arquivo texto e conte ocorrências de palavras.

## Regras
- Use a estrutura indicada no enunciado.
- Trate entradas inválidas com mensagens claras.
- Quando houver arquivo, leia com segurança e feche os recursos corretamente.

## Entrada
Arquivo com texto simples.

## Saída
Mostre as palavras e suas frequências.

## Exemplo
### Entrada
```text
texto.txt
```
### Saída
```text
java = 3
poo = 2
classe = 1
```
