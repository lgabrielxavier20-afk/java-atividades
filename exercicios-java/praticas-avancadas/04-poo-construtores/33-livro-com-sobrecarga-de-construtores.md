# 33 - Livro com Sobrecarga de Construtores

## Categoria
Construtores e POO

## Nível
Intermediário

## Contexto
Treino com classes, construtores, this, sobrecarga, métodos de instância e toString.

## Enunciado
Crie a classe Book com dois construtores, um básico e um completo, e um método para aumentar o preço.

## Regras
- Crie as classes pedidas com construtores e métodos de instância.
- Use this quando houver ambiguidade entre atributos e parâmetros.
- Implemente toString quando o exercício pedir exibição formatada.

## Entrada
Título, autor, preço e quantidade.

## Saída
Mostre os dados do livro antes e depois do aumento.

## Exemplo
### Entrada
```text
Java na Pratica
Nelio Alves
50
2
10
```
### Saída
```text
Java na Pratica, Nelio Alves, $ 50.00, 2 units, Total: $ 100.00
Java na Pratica, Nelio Alves, $ 55.00, 2 units, Total: $ 110.00
```
