# 57 - Reservas de Quarto

## Categoria
Listas

## Nível
Intermediário

## Contexto
Treino com ArrayList, buscas, remoções, ordenação e manipulação de coleções dinâmicas.

## Enunciado
Cadastre reservas com data de entrada e saída e impeça conflitos de período.

## Regras
- Use List quando a quantidade de registros não for fixa.
- Trabalhe com busca por id, nome ou posição quando o enunciado pedir.
- Mostre o resumo final de forma organizada.

## Entrada
Número do quarto, data inicial e data final.

## Saída
Mostre a reserva quando não houver conflito.

## Exemplo
### Entrada
```text
101
2026-07-10
2026-07-15
```
### Saída
```text
Reserva criada para o quarto 101
```
