# 51 - Funcionários por ID

## Categoria
Listas

## Nível
Intermediário

## Contexto
Treino com ArrayList, buscas, remoções, ordenação e manipulação de coleções dinâmicas.

## Enunciado
Leia vários funcionários, armazene em uma lista e aumente o salário de um funcionário escolhido pelo id.

## Regras
- Use List quando a quantidade de registros não for fixa.
- Trabalhe com busca por id, nome ou posição quando o enunciado pedir.
- Mostre o resumo final de forma organizada.

## Entrada
Funcionários com id, nome e salário, mais o id de busca e a porcentagem de aumento.

## Saída
Mostre a lista final com os salários atualizados.

## Exemplo
### Entrada
```text
1
Ana
3000
2
Bruno
2500
3
Carla
2800
2
10
```
### Saída
```text
Ana, 3000.00
Bruno, 2750.00
Carla, 2800.00
```
