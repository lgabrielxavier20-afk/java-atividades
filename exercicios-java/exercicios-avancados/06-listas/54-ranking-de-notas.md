# 54 - Ranking de Notas

## Categoria
Listas

## Nível
Intermediário

## Contexto
Treino com ArrayList, buscas, remoções, ordenação e manipulação de coleções dinâmicas.

## Enunciado
Leia nome e nota de alunos em uma lista e mostre o ranking em ordem decrescente.

## Regras
- Use List quando a quantidade de registros não for fixa.
- Trabalhe com busca por id, nome ou posição quando o enunciado pedir.
- Mostre o resumo final de forma organizada.

## Entrada
Nome e nota de vários alunos.

## Saída
Mostre os três primeiros colocados.

## Exemplo
### Entrada
```text
Ana
9.5
Bruno
8.2
Carla
9.1
Diego
7.0
```
### Saída
```text
1o Ana = 9.5
2o Carla = 9.1
3o Bruno = 8.2
```
