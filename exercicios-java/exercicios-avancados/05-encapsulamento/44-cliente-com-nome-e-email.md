# 44 - Cliente com Nome e Email

## Categoria
Encapsulamento

## Nível
Intermediário

## Contexto
Treino com atributos privados, getters, setters, validações e regras de negócio.

## Enunciado
Crie uma classe Client com getters, setters e validação simples de e-mail.

## Regras
- Mantenha os atributos privados quando o exercício pedir encapsulamento.
- Crie getters e setters apenas para o que fizer sentido.
- Valide valores inválidos dentro dos métodos da classe.

## Entrada
Nome e e-mail.

## Saída
Mostre o cliente com os dados atualizados.

## Exemplo
### Entrada
```text
Ana
ana@email.com
```
### Saída
```text
Cliente cadastrado: Ana / ana@email.com
```
