# 19 - Quantidade de palavras

## Categoria
Strings

## Nível
Básico

## Contexto
Exercícios para manipular textos, separar palavras e aplicar comparacoes de string.

## Enunciado
Leia uma frase e conte quantas palavras ela possui.

## Regras
- Use os metodos de String quando eles simplificarem a solucao.
- Trate espacos em branco com cuidado.
- Se houver comparacao de texto, pense em maiusculas e minusculas.

## Entrada
Uma frase.

## Saída
Mostre a quantidade de palavras.

## Exemplo
### Entrada
```text
Aprender Java exige pratica
```
### Saída
```text
Palavras = 4
```
