# 20 - Normalizar texto

## Categoria
Strings

## Nível
Básico

## Contexto
Exercícios para manipular textos, separar palavras e aplicar comparacoes de string.

## Enunciado
Leia uma frase e mostre o texto em minusculo sem espacos duplos no meio.

## Regras
- Use os metodos de String quando eles simplificarem a solucao.
- Trate espacos em branco com cuidado.
- Se houver comparacao de texto, pense em maiusculas e minusculas.

## Entrada
Uma frase com espacos extras.

## Saída
Mostre a frase tratada.

## Exemplo
### Entrada
```text
  Java   para    iniciantes  
```
### Saída
```text
java para iniciantes
```
