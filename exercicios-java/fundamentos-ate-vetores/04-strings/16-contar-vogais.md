# 16 - Contar vogais

## Categoria
Strings

## Nível
Básico

## Contexto
Exercícios para manipular textos, separar palavras e aplicar comparacoes de string.

## Enunciado
Leia uma frase e conte quantas vogais ela possui.

## Regras
- Use os metodos de String quando eles simplificarem a solucao.
- Trate espacos em branco com cuidado.
- Se houver comparacao de texto, pense em maiusculas e minusculas.

## Entrada
Uma frase completa.

## Saída
Mostre a quantidade de vogais.

## Exemplo
### Entrada
```text
Java e divertido
```
### Saída
```text
Vogais = 7
```
