# 30 - Contatos da agenda

## Categoria
Vetores de objetos

## Nível
Intermediário

## Contexto
Exercicios de arrays com classes, para praticar objetos guardados em posicoes do vetor.

## Enunciado
Leia nome e telefone de N contatos e depois um nome de busca. Informe o telefone quando encontrar.

## Regras
- Crie uma classe simples para representar cada item do vetor.
- Guarde um objeto completo em cada posicao do array.
- Percorra o vetor para calcular medias, contagens e buscas.

## Entrada
Numero de contatos, dados de cada contato e nome pesquisado.

## Saída
Mostre o telefone encontrado ou a mensagem nao encontrado.

## Exemplo
### Entrada
```text
2
Ana
9999
Bruno
8888
Bruno
```
### Saída
```text
Telefone = 8888
```
