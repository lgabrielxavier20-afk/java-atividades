# 27 - Produtos em estoque

## Categoria
Vetores de objetos

## Nível
Intermediário

## Contexto
Exercicios de arrays com classes, para praticar objetos guardados em posicoes do vetor.

## Enunciado
Leia nome, preco e quantidade de N produtos. Mostre o produto mais caro e o valor total do estoque.

## Regras
- Crie uma classe simples para representar cada item do vetor.
- Guarde um objeto completo em cada posicao do array.
- Percorra o vetor para calcular medias, contagens e buscas.

## Entrada
Numero de produtos e os dados de cada produto.

## Saída
Mostre o total do estoque e o produto com maior preco.

## Exemplo
### Entrada
```text
3
Mouse
80
2
Teclado
120
1
Cabo
30
5
```
### Saída
```text
Total do estoque = 310.00
Mais caro = Teclado
```
