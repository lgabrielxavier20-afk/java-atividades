# 28 - Alunos aprovados

## Categoria
Vetores de objetos

## Nível
Intermediário

## Contexto
Exercicios de arrays com classes, para praticar objetos guardados em posicoes do vetor.

## Enunciado
Leia o nome e as tres notas de N alunos usando um vetor de objetos. Mostre media final e aprovados.

## Regras
- Crie uma classe simples para representar cada item do vetor.
- Guarde um objeto completo em cada posicao do array.
- Percorra o vetor para calcular medias, contagens e buscas.

## Entrada
Numero de alunos e, para cada um, nome e tres notas.

## Saída
Mostre a media final de cada aluno e a quantidade de aprovados.

## Exemplo
### Entrada
```text
2
Ana
7
8
9
Bruno
5
6
4
```
### Saída
```text
Ana = 8.00
Bruno = 5.00
Aprovados = 1
```
