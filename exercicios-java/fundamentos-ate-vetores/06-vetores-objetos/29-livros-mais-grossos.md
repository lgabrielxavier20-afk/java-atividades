# 29 - Livros mais grossos

## Categoria
Vetores de objetos

## Nível
Intermediário

## Contexto
Exercicios de arrays com classes, para praticar objetos guardados em posicoes do vetor.

## Enunciado
Leia titulo, autor e paginas de N livros e mostre qual tem mais paginas.

## Regras
- Crie uma classe simples para representar cada item do vetor.
- Guarde um objeto completo em cada posicao do array.
- Percorra o vetor para calcular medias, contagens e buscas.

## Entrada
Numero de livros e os dados de cada livro.

## Saída
Mostre o livro com maior numero de paginas.

## Exemplo
### Entrada
```text
3
Java Basico
Nelio
240
POO na pratica
Maria
310
Vetores
Ana
180
```
### Saída
```text
Livro mais grosso = POO na pratica
```
