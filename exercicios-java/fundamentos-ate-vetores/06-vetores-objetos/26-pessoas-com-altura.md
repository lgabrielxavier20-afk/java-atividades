# 26 - Pessoas com altura

## Categoria
Vetores de objetos

## Nível
Intermediário

## Contexto
Exercicios de arrays com classes, para praticar objetos guardados em posicoes do vetor.

## Enunciado
Leia nome, idade e altura de N pessoas. Mostre a altura media e os nomes das pessoas com menos de 16 anos.

## Regras
- Crie uma classe simples para representar cada item do vetor.
- Guarde um objeto completo em cada posicao do array.
- Percorra o vetor para calcular medias, contagens e buscas.

## Entrada
Numero de pessoas e, para cada uma, nome, idade e altura.

## Saída
Mostre a altura media, a porcentagem de menores de 16 anos e os nomes desses menores.

## Exemplo
### Entrada
```text
5
Joao
15
1.82
Maria
16
1.60
Teresa
14
1.58
Carlos
21
1.65
Paulo
17
1.78
```
### Saída
```text
Altura media: 1.69
Pessoas com menos de 16 anos: 40.0%
Joao
Teresa
```
