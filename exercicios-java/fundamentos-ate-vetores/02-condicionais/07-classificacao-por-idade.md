# 07 - Classificacao por idade

## Categoria
Condicionais

## Nível
Básico

## Contexto
Exercícios de if/else para treino de decisão, faixas de valores e validação simples.

## Enunciado
Leia a idade de uma pessoa e classifique como crianca, adolescente, adulto ou idoso.

## Regras
- Escolha a estrutura condicional mais clara para cada caso.
- Considere todos os intervalos citados no enunciado.
- Mantenha as mensagens exatamente como pedido.

## Entrada
Uma idade inteira.

## Saída
Mostre a faixa etaria correspondente.

## Exemplo
### Entrada
```text
67
```
### Saída
```text
Idoso
```
