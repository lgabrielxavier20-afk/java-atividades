# 08 - Frete gratis

## Categoria
Condicionais

## Nível
Básico

## Contexto
Exercícios de if/else para treino de decisão, faixas de valores e validação simples.

## Enunciado
Leia o valor de um pedido e informe se ele tem frete gratis ou nao.

## Regras
- Escolha a estrutura condicional mais clara para cada caso.
- Considere todos os intervalos citados no enunciado.
- Mantenha as mensagens exatamente como pedido.

## Entrada
Valor do pedido.

## Saída
Mostre Frete gratis ou Frete cobrado.

## Exemplo
### Entrada
```text
250
```
### Saída
```text
Frete gratis
```
