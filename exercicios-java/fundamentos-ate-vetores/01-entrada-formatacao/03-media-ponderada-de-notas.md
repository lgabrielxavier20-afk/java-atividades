# 03 - Media ponderada de notas

## Categoria
Entrada e formatação

## Nível
Básico

## Contexto
Exercícios para treinar leitura de dados, tipos primitivos e saída formatada.

## Enunciado
Leia tres notas e seus pesos e calcule a media ponderada.

## Regras
- Leia os dados no console na ordem pedida.
- Use variáveis com tipos compatíveis com cada dado.
- Formate a saída com o padrão solicitado no enunciado.

## Entrada
Tres notas e tres pesos.

## Saída
Mostre a media ponderada com duas casas decimais.

## Exemplo
### Entrada
```text
7
8
9
2
3
5
```
### Saída
```text
Media ponderada = 8.17
```
