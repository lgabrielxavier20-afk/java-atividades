# 02 - Troco de compra

## Categoria
Entrada e formatação

## Nível
Básico

## Contexto
Exercícios para treinar leitura de dados, tipos primitivos e saída formatada.

## Enunciado
Leia o valor total da compra e o valor pago pelo cliente. Calcule o troco.

## Regras
- Leia os dados no console na ordem pedida.
- Use variáveis com tipos compatíveis com cada dado.
- Formate a saída com o padrão solicitado no enunciado.

## Entrada
Valor da compra e valor pago.

## Saída
Mostre o troco com duas casas decimais.

## Exemplo
### Entrada
```text
37.50
50.00
```
### Saída
```text
Troco = 12.50
```
