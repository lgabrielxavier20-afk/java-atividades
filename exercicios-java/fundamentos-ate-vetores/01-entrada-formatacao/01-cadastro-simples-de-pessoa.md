# 01 - Cadastro simples de pessoa

## Categoria
Entrada e formatação

## Nível
Básico

## Contexto
Exercícios para treinar leitura de dados, tipos primitivos e saída formatada.

## Enunciado
Leia nome completo, idade, cidade e altura de uma pessoa e mostre um resumo formatado.

## Regras
- Leia os dados no console na ordem pedida.
- Use variáveis com tipos compatíveis com cada dado.
- Formate a saída com o padrão solicitado no enunciado.

## Entrada
Nome completo, idade, cidade e altura.

## Saída
Mostre uma linha com os dados da pessoa.

## Exemplo
### Entrada
```text
Joao Pedro
19
Belo Horizonte
1.78
```
### Saída
```text
Joao Pedro, 19 anos, Belo Horizonte, 1.78 m
```
