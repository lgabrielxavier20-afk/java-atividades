# Mini Projeto 1 - Sistema de Notas

Projeto inicial em Java para praticar metodos, estruturas de repeticao e tomada de decisao.

## O que ele faz

- Le 5 notas de alunos
- Calcula media, maior e menor nota
- Conta aprovados e reprovados

## Conceitos treinados

- metodos estaticos
- if/else
- for
- acumuladores

## Arquivo principal

- `SistemaNotas.java`
